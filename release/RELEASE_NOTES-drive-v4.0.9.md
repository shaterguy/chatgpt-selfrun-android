# SelfRun Drive v4.0.9

v4.0.8 정식판의 프로젝트 등록 시 이름이 공통 환영 문구로 저장되는 문제만 수정했습니다.

- ChatGPT의 페이지 첫 번째 h1(예: 진수님 반갑습니다)은 프로젝트명 출처에서 제외합니다.
- 실제 프로젝트 제목 및 해당 프로젝트 URL과 일치하는 링크 텍스트를 사용합니다.
- 환영 문구·일반 ChatGPT 제목은 등록하지 않습니다. 이름이 확인되지 않으면 프로젝트 ID로 임시 표시합니다.
- 과거 잘못 저장된 환영 문구는 사용하지 않고, 정상 이름이 확인되면 기존 ID의 이름을 업데이트합니다.
- 프로젝트 URL, 기존 등록 목록, SelfRun 실행기, Drive 연동, 설정·원장·권한 등은 변경하지 않습니다.
